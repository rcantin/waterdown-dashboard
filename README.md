# Waterdown Dashboard

Clean local dashboard for Waterdown & Flamborough (Hamilton, ON).

## Sections
- **In the News** — local headlines (demo links to The Spec / FlamboroughToday)
- **Construction Updates** — placeholder + City of Hamilton construction link
- **Quick Reference** — garbage, city services, police
- **Crime Data** — summary stats from public HPS reports + simple chart

## Run
Open `index.html` in a browser, or serve statically (GitHub Pages, Netlify, etc.).
